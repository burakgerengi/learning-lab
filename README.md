# learning-lab

A personal repository for programming practice, experiments, exercises, and small projects created while learning computer science and software development.

This repository is intentionally broad. It may contain anything from data structures and algorithms to language exercises, small applications, experiments with libraries and tools, or implementations of concepts I am currently studying.

## purpose

The goal of this repository is to practice by building.

Instead of only reading about a concept, I use this repository to implement it, experiment with different approaches, make mistakes, and improve the code over time.

The repository also serves as a record of my progress. Older code may be simpler or less polished than newer work, and some projects may remain unfinished.

## structure

There is no fixed technology stack or strict subject scope.

Different directories may use different programming languages, libraries, tools, and project structures depending on what I am learning at the time.

Larger or more complete projects may eventually be moved into their own repositories.

## notes

The code here is mainly written for learning and experimentation.

Some implementations may be incomplete, simplified, inefficient, experimental, or intentionally written to demonstrate a specific concept.

The repository is expected to change over time as I learn new things, revisit older code, and improve existing implementations.

## disclaimer

This repository is intended for educational and personal use.

Any code reused outside this repository should be reviewed, tested, and adapted to the requirements of the target project.
